## 🚀 Como Executar

```bash
# Clone o repositório
git clone https://github.com/marcos-thebest/2TDSPS-2026.git

# Entre na pasta do projeto desejado
cd 2TDSPS-2026/modulo-03

# Rode com Maven
./mvnw spring-boot:run
```

A aplicação sobe por padrão em:
```
http://localhost:8080
```

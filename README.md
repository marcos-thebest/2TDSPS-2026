## ◈ Sobre

Este repositório é o meu **espaço de estudo** dedicado exclusivamente a aprender **Dart** — a linguagem por trás do Flutter.

Aqui não tem produto final, tem **processo**: cada arquivo é um passo na curva de aprendizado, desde a sintaxe básica até conceitos mais avançados da linguagem.

> ⚙️ **Propósito:** praticar, errar, corrigir e evoluir — um commit de cada vez.

---

## ◈ O que estou explorando

- [x] Sintaxe básica (variáveis, tipos, operadores)
